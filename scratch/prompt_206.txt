# MASTER IMPLEMENTATION PROMPT — Mobile Experience Polish (Homepage + Dashboard + Site-Wide)
**Target system:** Cycle of Chart / Trading Reality (existing Next.js + TypeScript + PostgreSQL/Prisma production app)
**For:** Antigravity (or any coding agent extending the existing codebase)

---

## 0. Objective

On mobile, the Homepage and Dashboard (and the site generally) should feel clean, easy to read, and effortless to navigate with a thumb — no cramped cards, no tiny tap targets, no awkward wrapping or horizontal scroll. This is a **mobile-only polish pass**, not a redesign.

**Reference for inspiration only:** a screenshot from a different trading-journal app (tradefxbook.com) shows the *kind* of mobile clarity to aim for — a clean 2-column stat-card grid, a condensed performance chart with simple time-range tabs (1D/1W/1M/3M/ALL), and a fixed bottom navigation bar for the most-used sections. **Do not copy its colors, branding, icons, or exact layout** — Cycle of Chart's existing dark/graphite + cyan-blue premium fintech identity stays exactly as-is. Borrow only the *structural* ideas: tighter grouping, simpler nav, less visual noise per screen.

---

## 1. Non-Negotiable Constraints

**Do NOT:**
- Change desktop/laptop layout, spacing, colors, typography, or behavior — this is mobile-only.
- Redesign the visual identity (dark/graphite/gold-or-cyan palette, existing fonts, existing card styles, existing glow/border effects) — only adjust sizing, spacing, and arrangement for small screens.
- Remove or hide any existing functionality — every sidebar item, dashboard stat, and homepage section must remain reachable on mobile, just better organized.
- Rebuild pages from scratch. Adjust the existing responsive breakpoints/components.
- Break existing mobile-specific rules already in place (e.g. the cursor-glow effect already disabled on mobile stays disabled).

## 2. Homepage — Mobile Pass

Audit the existing homepage sections on small screens (~360–414px width) and fix, without altering desktop:

- Any preview/demo cards (e.g. the "Institutional Trader Journal & Performance" preview block): ensure stat numbers and labels don't crowd or truncate.
- The dual Founder/Cycle of Chart profile section: confirm both profile cards stack cleanly (not side-by-side if that causes squeezing) and the centralized social-icon row stays legible and tappable (adequate spacing between icons for touch).
- Any multi-column grids (e.g. the tools/platforms cards, roadmap stage cards): collapse to 1 column on narrow screens with consistent spacing.

## 3. Dashboard — Mobile Pass

The dashboard currently shows, among other things: a top stat row (Journal Entries, Trade Win Rate, My Resources, Today's Discipline, Your Global Rank), a plan/usage summary row (trial or plan status, per-feature limits), a market-time card, and a left sidebar (Overview, Roadmap, Library, Trade Journal, Daily Routine, Position Size Calculator, Orders & Invoices, Direct Support, Leaderboard, Account Settings).

**Fixes needed on mobile:**
- **Stat cards:** rearrange into a clean, evenly-spaced 2-column grid (matching the *clarity* of the reference screenshot's card grid, in Cycle of Chart's own visual style) instead of a cramped single row.
- **Navigation:** the desktop sidebar should not simply shrink or scroll sideways on mobile. Convert it to a mobile-appropriate pattern — e.g. a fixed bottom navigation bar with the 4–5 most-used sections (Overview, Trade Journal, Daily Routine, Leaderboard, and a "More" item that opens the remaining sections in a drawer/sheet) — inspired by the reference screenshot's bottom-nav structure, but styled to match Cycle of Chart's existing dark/cyan identity, not copied visually.
- **Plan/usage row:** ensure limits and upgrade prompts (e.g. "Get Pro" / "Get Premium") remain fully readable and tappable without horizontal scrolling.
- **Charts** (e.g. Performance Analytics & Growth Curve): ensure they resize to fit the viewport width, remain legible, and that tab controls (Balance Curve / Growth % / Period P&L) are large enough to tap comfortably.
