# Cycle of Chart — Operations & Admin Console

A dedicated, standalone Operations & Admin Panel for managing student enrollments, bKash / Nagad / Rocket payment approvals, access grants, support inquiries, and audit trails.

## Features
- **Executive KPI Analytics**: Live tracking of verified revenue (BDT), pending verification volume, student count, and ticket resolution rate.
- **Manual Payment Verification Queue**: 1-click approval for bKash, Nagad, and Rocket payments with automatic access provisioning, or rejection with customizable reason templates.
- **Student & Access Management**: Search students, change administrative roles, and manually grant or revoke digital packages.
- **Support Desk Operations**: View student inquiries, update ticket status, and resolve issues.
- **Gateway & Notice Settings**: Live management of bKash, Nagad, and Rocket numbers and announcement banners.
- **Immutable Audit Trail**: Security log recording every administrative action with actor and timestamp.

## Getting Started

```bash
# Run locally (Port 3001)
npm install
npm run dev
```
